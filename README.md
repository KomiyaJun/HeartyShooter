# 作品タイトル、概要
**タイトル**
HeartyShooter

**概要**
本作は、C++およびSiv3Dを用いて制作した2Dトップダウン視点のシューティングゲームです。
プレイヤーは迫りくる敵の群れを撃退しながらいき残りを図ります。
一定数の敵を倒すことで出現するボスを撃破すると、ゲームのレべルが上昇し、敵が強くなる「ループ(周回)要素」を取り入れ、繰り返し遊べるゲームサイクルを構築しています。

# 主な機能と特徴
**オブジェクトプールを活用したメモリの効率化**
ゲーム中で大量に発生する「弾（Bullet）」や「スコアアイテム」などについて、頻繁な生成・破棄による負荷（処理落ち）を防ぐため、オブジェクトプール領域を事前に確保して再利用する設計を取り入れ、メモリ効率の最適化を図っています。

**複数種類の敵キャラクターによる戦闘の多様化**
 接近して攻撃を行うタイプ（Grunt）や、遠距離から精確に狙いを定めて連射するタイプ（Sniper）など、異なる行動パラメータ・AIを持つ敵を実装し、ゲームプレイに変化を持たせています。

 **状態遷移による進行管理と敵AIの行動管理**
 Wave制による敵の出現やボス戦といった「ゲーム進行のフェーズ管理」を行うとともに、敵との距離に応じて索敵や攻撃を切り替える「敵AIの行動・状態管理」を実装し、ゲーム全体の状況と個別の動きを制御しています。

 #担当箇所、注力ポイント
 **・担当箇所**
個人製作なのでコードの部分は自作です。
タイトルで使われている画像は生成AIを利用したものになっています。

**・注力ポイント**

**1.オブジェクトプールを活用したパフォーマンスの最適化**
 シューティングゲームの性質上、ゲーム中に大量の「弾」や「ドロップアイテム」が発生します。最初は生成と破棄を繰り返していましたが、処理落ちの原因になり得るため、オブジェクトプールパターンを採用しました。事前に必要な数を変数として確保（BulletPool）し、非アクティブなオブジェクトを使い回すことで、メモリ割り当てのオーバーヘッドを削減し、ゲーム終盤でもフレームレートを落とさず快適に遊べるよう工夫しました。

**2.列挙型（Enum）を用いたシーン・状態遷移の厳密な管理**
ゲーム全体の流れを破綻なく制御するため、列挙型を用いてステートマシン（状態遷移）を実装しました。 
・画面遷移を行う GameScene（タイトル、説明、ゲーム本編、リザルト） 
・ゲーム内の演出を切り替える GamePhase（プレイ中、ボス撃破演出、エンディング演出） 
・敵のWave進行を切り替える GameState（Wave1出現〜ボス戦〜クリア） 
これら3つの状態変数を独立して組み合わせることで、複雑なゲーム進行や演出をわかりやすく、バグが入り込みにくいコード構造に整理しました。
